# KWI Zipper

Распаковка/запаковка KWI-файлов (Toyota NSZT-W68T).

## Что такое KWI

KWI — контейнер прошивки головного устройства. Состоит из двух частей:

```
┌──────────────────────┬─────────────────────────────────────┐
│                      │                                     │
│   KWI-заголовок      │        ext4 файловая система         │
│   (~1.4 МБ)          │        (~320 МБ)                    │
│                      │                                     │
│  • magic: 0x0001     │  Корневая ФС Linux:                 │
│  • ID: "HL57"        │  ├── bin/          → busybox        │
│  • ID: "VL57"        │  ├── sbin/init     → ../vns/bin/pmng│
│  • карта блоков      │  ├── vns/bin/*.so  (логика ГУ)      │
│  • дерево каталогов  │  ├── vns/ko/*.ko   (драйверы ядра)  │
│  • список файлов     │  ├── etc/          (конфиги)         │
│                      │  └── ...                            │
└──────────────────────┴─────────────────────────────────────┘
```

Заголовок — служебная информация загрузчика (карта размещения файлов, список имён).
Файловая система — стандартная Linux ext4 со всеми файлами прошивки.

**Это НЕ ZIP.** 7zip видит ZIP потому что где-то внутри 320 МБ данных
случайно лежат байты `PK` (сигнатура ZIP-архива). При «распаковке» через 7zip:
- теряются symlink'и (sbin/init → pmng превращается в пустой файл)
- слетают права доступа
- часть данных не извлекается

ГУ с таким KWI не загрузится. Нужен kwizipper.

## Как работает kwizipper.sh

### unpack

```
KWI → python3: ищем ext4 по сигнатуре 0xEF53 + валидация суперблока
    → dd: отрезаем заголовок
    → чистый ext4 образ
    → debugfs rdump: выгружаем все файлы в директорию
```

`debugfs` читает ext4 напрямую, без монтирования и без sudo.
Symlink'и, права, имена — всё сохраняется как в оригинале.

### pack

```
директория → mkfs.ext2 -d: создаём новый ext4 образ (+20% свободного места)
           → e2fsck -fy: проверка целостности
           → cat: приклеиваем сохранённый заголовок → KWI
```

Всё без sudo. Размер KWI на выходе — минимально возможный.

## Использование

```bash
./kwizipper.sh unpack <kwi> [dir]   # KWI → директория
# (меняешь файлы)
./kwizipper.sh pack [dir] <kwi_out> # директория → KWI
```

## Зависимости

- `e2fsprogs` — debugfs, mkfs.ext2, e2fsck, resize2fs
- `python3`
- Без sudo
